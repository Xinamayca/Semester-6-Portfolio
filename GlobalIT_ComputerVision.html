A color image is made of 3 layers stacked together: a Red layer, a Green layer, and a Blue layer. Together, these three layers create a full color picture.

When we use original_image[:, :, 0] to extract just one layer, we get a single 2D array of numbers. The code then uses cmap='gray' inside plt.imshow() which directly tells matplotlib to display it in grayscale, which is why all three channels appear in black and white.

To fix this, we remove cmap='gray' and instead reconstruct a full 3-layer image for each channel, replacing the other two layers with zeros (empty/blank). For example, the red image is built as [R, 0, 0] keeping the red layer and zeroing out green and blue. This way, matplotlib receives a proper RGB image and displays it in the correct color.

3. Color Detection

Color detection exercise using HSV color space

Sometimes, we need to express color in a different format rather than just RGB. For example, HSV is a commonly used way to represent color.

HSV Color Model¶

  • H = Hue Represents the actual color type (red, orange, yellow, green, blue, etc.). Hue is usually represented as an angle around a color wheel.

  • S = Saturation Represents the intensity or purity of the color.

    • High saturation → vivid, strong color
    • Low saturation → washed out or closer to gray

  • V = Value (also called Brightness) Represents how bright or dark the color appears.

    • High value → brighter
    • Low value → darker

Why is HSV preferred in some computer vision applications?¶

HSV is often preferred because human visual perception understands Hue, Saturation, and Value more naturally than separate Red, Green, and Blue components.

Compared with RGB:

  • Hue isolates the actual color information.
  • Saturation controls color intensity independently.
  • Value controls brightness independently.

This separation makes color-based operations such as object detection, segmentation, and tracking more robust under changing lighting conditions.

Below, we are going to create a color detection application that detects specified colors in a video stream.

First, we will start with a blue color detector.

To achieve this:

  1. Capture video frames from a camera.
  2. Convert each captured frame from RGB/BGR into HSV color space.
  3. Define an HSV value range corresponding to the blue color.
  4. Detect pixels whose HSV values fall within the specified range.
  5. Highlight or report the detected blue regions in real time.

import numpy as np
import cv2 as cv

cap = cv.VideoCapture(0)
ret = True
cv.namedWindow('Original',cv.WINDOW_NORMAL)
cv.namedWindow('Mask',cv.WINDOW_NORMAL)
cv.namedWindow('Blue',cv.WINDOW_NORMAL)
while(ret):

    ret, frame = cap.read()

    # Convert BGR to HSV
    hsv = cv.cvtColor(frame, cv.COLOR_BGR2HSV)

    # define range of blue color in HSV
    lower_blue = np.array([100,50,50])
    upper_blue = np.array([140,255,255])
    
    # create a mask that only pixels within the range of lower_blue and upper_blue
    # will be labeled as 1, other as 0
    mask = cv.inRange(hsv, lower_blue, upper_blue)

    # Bitwise-AND mask and original image
    blue = cv.bitwise_and(frame, frame, mask = mask)

    cv.imshow('Original',frame)
    cv.imshow('Mask',mask)
    cv.imshow('Blue',blue)

    k = cv.waitKey(10) & 0xFF
    if k == 27:
        break
else: 
    print('Video capture fault, exit...')
    
cap.release()
cv.destroyAllWindows()

4. Pose Detection

Introduction to Pose Detection Using MediaPipe¶

Pose detection is a computer vision technique used to identify and track key points of the human body from images or video streamsP pose detection estimates the positions of important body joints and landmarks such as the shoulders, elbows, wrists, hips, knees, and ankles. These detected points can then be used to analyze human posture, movement, and actions.

One of widely usedular frameworks for real-time pose estimation is MediaPipe, an open-source machine learning framework developed by Google. MediaPapply CNN based model to can perform body landmark detection directly on live video streams, making it suitable for applications that require real-time performance.

MediaPipe Pose extracts a set of predefined body key points (landmarks) from each detected person. Each landmark contains:

  • x-coordinate → horizontal position of the key point
  • y-coordinate → vertical position of the key point
  • z-coordinate → estimated depth relative to the camera
  • visibility score → confidence that the landmark is visible

The pose model detects 33 body landmarks, covering the face, torso, arms, hands, and legs.

The general workflow for pose detection using MediaPipe is:

  1. Capture frames from a webcam or video source.
  2. Convert the image into the required color format.
  3. Process the frame using the MediaPipe Pose model.
  4. Extract body landmark coordinates.
  5. Visualize or analyze the dAnimation and virtual reality

In this exercise, we will use MediaPipe to detect human body landmarks and extract pose key points from a live video stream for further analysis and visualization.

import cv2 as cv
import mediapipe as mp

pose = mp.solutions.pose.Pose()
draw = mp.solutions.drawing_utils
style = mp.solutions.drawing_styles

cap = cv.VideoCapture(0)

while cap.isOpened():

    ret, frame = cap.read()
    if not ret:
        break

    results = pose.process(
        cv.cvtColor(frame, cv.COLOR_BGR2RGB)
    )

    if results.pose_landmarks:
        draw.draw_landmarks(
            frame,
            results.pose_landmarks,
            mp.solutions.pose.POSE_CONNECTIONS,
            landmark_drawing_spec=
                style.get_default_pose_landmarks_style()
        )

    cv.imshow(
        "Pose Detection",
        cv.flip(frame, 1)
    )

    if cv.waitKey(1) & 0xFF == 27:
        break

cap.release()
pose.close()
cv.destroyAllWindows()
